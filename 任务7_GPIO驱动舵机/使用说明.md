# 任务7 GPIO驱动舵机 - 使用说明 (OpenHarmony 1.0 / Hi3861)

## 文件清单
- `3.0_SG90_Mutex/SG90.c`   —— 学生作业版代码(同优先级3任务 + 互斥锁)
- `3.0_SG90_Mutex/BUILD.gn` —— 组件构建脚本
- `app_BUILD.gn`            —— 覆盖 app 目录下的 BUILD.gn(添加 SG90 组件)

## 放到虚拟机上 (VSCode Remote-SSH 连 harmony-vm)

OpenHarmony 源码目录下, app 应用位于:
```
<源码根目录>/applications/sample/wifi-iot/app/
```

1. 创建工程目录(参照作业要求, 复制 1.0_Hello_World 改名):
```bash
cd <源码根目录>/applications/sample/wifi-iot/app
mkdir 3.0_SG90_Mutex
```
2. 把 `SG90.c`、`BUILD.gn` 放入 `3.0_SG90_Mutex/`
3. 修改 `app/BUILD.gn`, 在 features 里加一行:
```python
lite_component("app") {
    features = [
        "1.0_Hello_World:hello_world",
        "2.0_TCRT_Timer:TCRT",
        "3.0_SG90_Mutex:SG90",   # 新增
    ]
}
```
> 注意: 若你 VM 上的 app 里没有 1.0_Hello_World / 2.0_TCRT_Timer, 只保留你现有 features 并追加
> `"3.0_SG90_Mutex:SG90"` 一行即可, 不要引用不存在的组件。

## 编译 (源码根目录, SSH 终端执行)
```bash
python build.py wifiiot
```
首次编译较慢, 成功后产物在:
```
out/wifiiot/Hi3861_wifiiot_app_allinone.bin
```

## 烧录与实验现象
- 串口开关打到 **5861** 端; 数据线连接电脑给小车供电(烧录不需要电池), **关闭小车电源开关**
- 用 HiBurn(或 DevEco) 下载 `Hi3861_wifiiot_app_allinone.bin`
- 按复位键后, 串口(115200)应循环打印:
```
Task1 run: servo left 45.      <- 任务1, 输出1次
(3秒后)
Task3 run: servo right 45.     <- 任务3, 输出2次
Task3 run: servo right 45.
Task2 run: servo center.       <- 任务2, 输出3次
Task2 run: servo center.
Task2 run: servo center.
```
- 舵机动作: 左转45度 -> 右转45度 -> 居中, 循环往复

## 代码设计说明
三个任务同优先级(priority=24), 完全靠互斥锁 + 错开延时决定运行顺序:
- 任务1 先创建无延时 -> 先拿锁(输出1次/左45°/持锁3秒)
- 任务3 osDelay(300)=3秒后拿锁(输出2次/右45°/持锁1秒)
- 任务2 osDelay(400)=4秒后拿锁(输出3次/居中/持锁1秒)
- 共享资源 `angle_flag` 仅在互斥锁保护下写入, 体现"独占式处理共享资源"
