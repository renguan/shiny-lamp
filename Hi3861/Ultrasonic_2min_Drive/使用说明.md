# 教室自主行驶 2 分钟 · 超声波避障（Ultrasonic_2min_Drive）

> 本工程是「教室自主行驶 2 分钟」任务的**全新最终版**，与旧版 `Auto_Drive_2min`（v1/v2/v3 反复迭代版）无关、互不影响。烧录本固件即可整机运行：小车自动（非遥控）行驶约 2 分钟，用超声波测距避障，全程不撞东西，到点自动停车。

## 1. 需求与方案

- **需求**：小车放在教室里自动（非遥控）行驶约 2 分钟，不撞到任何东西；利用**超声波测距**完成避障。
- **方案（QST 先锋号小车，Hi3861 侧）**：
  - HC-SR04 超声波装在 GPIO2 舵机云台上，可左/中/右转头测距（TRIG=GPIO7、ECHO=GPIO8）；
  - 电机由 Hi3861 经 **UART2（GPIO11/12，115200）** 发协议帧（`0xFC+左向+左速+右向+右速+0xFD`）指挥 STM32 底盘驱动；
  - 行为循环：前进（云台居中盯正前）→ 判障（<30cm×2 次 或 <14cm 1 次）→ 反转制动 250ms → 后退 500ms → 云台扫左/右选较空一侧 → 小步转向（每步验证正前打通即停）→ 继续前进；两侧都堵则原地调头 180°；总时长到 **120s 自动停车**。
  - **所有运动指令都是“心跳式”持续重发**（每 30ms 一帧），不会因为单帧丢失/STM32 需要连续指令而车不动（MotorDiag 实测结论：单发一帧不动、持续发帧能动）。

## 3. 硬件映射

| 外设 | 引脚/接口 | 说明 |
|---|---|---|
| SG90 舵机云台 | GPIO2 | 软件 PWM，20ms 周期；超声波探头装在云台上 |
| HC-SR04 TRIG | GPIO7 | 输出 20us 触发脉冲 |
| HC-SR04 ECHO | GPIO8 | 输入，量回波高电平宽度 |
| STM32 通信 | UART2 = GPIO11(TX)/GPIO12(RX) | 115200，8N1，协议帧见上 |
| 电机 | STM32 侧（L9110S×2） | Hi3861 不直接驱动 |

## 5. 烧录（HiBurn）

1. 串口开关拨到 **5861 端**；
2. 数据线供电（**关闭小车电源开关**）；
3. HiBurn：选择芯片 Hi3861、串口 COMx、波特率 115200；
4. 加载 `Hi3861_wifiiot_app_allinone.bin` → Connect → 按板上复位键开始烧录；
5. 烧完**打开小车电源开关**（电机用电池供电），按复位重启。

## 6. 实车验证流程

1. **先做链路自检**（可选）：串口开关拨 **STM32 端**，串口助手 115200，手动 HEX 发送：
   - 前进：`FC 00 64 00 64 FD`
   - 后退：`FC 01 50 01 50 FD`
   - 左转：`FC 01 5F 00 5F FD`　右转：`FC 00 5F 01 5F FD`
   能前后左右动 → STM32 底盘固件正常；若后退/转向不动 → **STM32 端固件不是“解析 0xFC 帧”的底盘固件**（可能被任务21~24 的 Keil 固件覆盖），先重烧底盘固件再做第 2 步。
2. 空旷地面放一个纸箱在车前约 40cm，烧录后观察：
   - 串口 115200（5861 端）应打印 `[2min] forward...` → `OBSTACLE dist=..` → `scan: L=.. R=..` → `steer LEFT/RIGHT`；
   - 车应在纸箱前停下、后退、转向空处、继续前进（**若车朝纸箱转 = 左右反了，见第 7 节 a/b**）；
3. 短测 OK 后正式跑 2 分钟：教室放好车 → 按复位 → 车自己跑，全程不撞、到 120s 打印 `2 MIN DONE` 自动停。

## 7. 方向/手感核对清单（烧录后必看）

| 现象 | 改法 |
|---|---|
| a. 避障时车朝“障碍”那边转（该左转右、该右转左） | `ultrasonic_2min_drive.c` 里交换 `car_left()`/`car_right()` 两行实现 |
| b. 云台扫到的“左”读数其实是车右侧（云台装反） | 交换 `SG90_LEFT`/`SG90_RIGHT` 脉宽宏（或交换 `dl`/`dr` 赋值） |
| c. 直行明显跑偏 | 调 `SPEED_FWD_L`/`SPEED_FWD_R` 差值：偏哪边就调对应轮（反偏则两宏对调） |
| d. 判障太晚/刹不住 | 调大 `EVADE_CM`（如 35）或 `BRAKE_MS`（如 350） |
| e. 空旷处乱躲（误判） | 调小 `EVADE_CM`（如 25）或调低 `SPEED_FWD_L/R` |
| f. 转向角度不合适 | 调 `TURN_STEP_MS`（每步时长）或 `TURN_90_STEPS`/`TURN_180_STEPS`（步数）或 `SPEED_TURN` |
| g. 不想等 3s 起步 | 调小 `START_DELAY_MS` |

> 先改 a/b（方向），再改 c~g（手感）。所有参数都是文件顶部宏，改完重新编译即可。

## 8. 主要参数速查（`ultrasonic_2min_drive.c` 顶部）

| 宏 | 默认 | 含义 |
|---|---|---|
| `SPEED_FWD_L/R` | 70/70 | 前进速度（左右可差速纠正跑偏） |
| `SPEED_BRAKE` / `BRAKE_MS` | 110 / 250 | 反转制动速度 / 时长 |
| `SPEED_BACK` / `BACKUP_MS` | 70 / 500 | 遇障后退速度 / 时长 |
| `SPEED_TURN` / `TURN_STEP_MS` | 95 / 400 | 原地转向速度 / 一小步时长 |
| `TURN_90_STEPS` / `TURN_180_STEPS` | 4 / 7 | 90° / 180° 转向步数 |
| `EMERGENCY_CM` | 14 | 低于此值单次立即判障 |
| `EVADE_CM` | 30 | 低于此值连续 2 次判障 |
| `SIDE_MIN_CM` | 35 | 两侧都低于此值 → 调头 180° |
| `GO_CM` | 45 | 转向中正前高于此值 = 已打通，停转 |
| `START_DELAY_MS` / `RUN_TOTAL_MS` | 3000 / 120000 | 起步延迟 / 总运行时长 |

## 9. 常见问题

- **烧录后串口无输出**：开关没拨 5861 端 / 波特率不对（115200）/ 没按复位。
- **车完全不动**：先做第 6.1 链路自检；电池开关没开；STM32 未解析 0xFC 帧。
- **只前进、不避障**：看串口有没有 `OBSTACLE`；没有 → 超声波没读数/阈值太小；有 → 按第 7 节核对转向方向。
- **2 分钟没到就停**：检查是不是避障循环里 `time_up` 提前触发（剩余 <3s 提前收车是正常设计）。
